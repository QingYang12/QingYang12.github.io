单词卡与间隔复习 · Memory Cards 隐私政策

生效日期：2026-07-20　版本：1.0

核心承诺

本扩展不会向开发者收集、出售或共享个人信息，不投放广告，不做跨站跟踪，不加载远程代码。除下文明确说明的测速或用户主动系统分享外，功能均在用户设备本地完成。

1. 扩展用途

把用户主动选择或输入的学习内容制作成卡片，并用本地间隔算法安排复习。

2. 本地处理与存储

卡片正反面、来源 URL、复习时间、评分、学习统计以及用户自愿填写的 AI 接口配置保存在 chrome.storage.local。

用户主动创建的卡片保存在本机；AI 素材只会在用户主动点击后发送到其选择的接口。

3. 外部服务与数据传输

默认本地填空不联网。仅当用户配置自己的 OpenAI 兼容接口并点击“AI 出题”时，当前素材才会发送到用户选择的服务商；该服务商按其隐私政策处理数据，开发者不会收到数据。

4. 权限用途

  • storage：保存卡片、复习进度和可选 AI 接口配置。
  • contextMenus：添加“将选中文字添加为单词卡”菜单。
  • activeTab：在用户点击右键菜单时读取该标签页标题和 URL 作为卡片来源。
  • optional host permissions：仅在用户点击 AI 出题时，按其填写的 API 域名弹窗申请访问权限；不预先获取全网权限。

5. 保留、删除与安全

本地数据保留至用户在插件内删除、清除 Chrome 扩展数据或卸载插件。开发者没有该数据的副本。扩展仅包含随安装包分发的 HTML、CSS、JavaScript 和图片资源。

6. 儿童、变更与联系

本扩展不面向收集儿童个人信息。政策重大变更会随扩展版本更新并修改本页日期。如有隐私问题，请通过 Chrome Web Store 产品支持页面联系开发者。
