Support for the iOS app · 超级3D建模工厂

Contact support

Email 736749722@qq.com. Include your app version, iPhone/iPad model, iOS version and a short description of the problem. Do not include passwords or confidential design files.

Open a model

Tap “进入超级3D建模工厂” to enter the library, then open an included project. Drag to rotate and pinch to zoom.

Import and export

Import accepts compatible JSON projects produced by this app. It does not import general-purpose CAD formats such as STEP or STL. Tap export to choose a destination in Files. To move a project to another device, transfer the exported file and import it there.

Missing projects

The library is stored locally. Import your exported backup if a project is missing. Clearing the library deletes its local project records; exported copies are managed separately.

Language

The current app interface is primarily Simplified Chinese.
