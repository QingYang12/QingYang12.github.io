AI 网页结构化采集与字段助手隐私政策

生效日期：2026 年 7 月 28 日　版本：1.2.0

扩展在侧边栏列出当前窗口已打开的普通网页，并且只在用户选择标签页并点击采集后读取该网页的配置字段。

1. 网页读取

侧边栏使用标签页标题、URL 和标签页编号生成来源选择列表。用户选择来源并执行采集后，扩展会临时读取该标签页的可见文本、链接、图片地址及用户配置的 CSS 选择器结果。普通采集、表格预览、去重和导出均在浏览器本地完成。

2. AI 字段建议

只有用户点击“AI 建议字段”时，所选页面的标题和最多约 10000 字的文本轮廓才会发送至所选 AI 服务。免费模式通过 test.wanghaonet.com 调用 qwen3.7-plus；自己的 API 模式直接调用用户配置的地址，Key 仅保存在本机。

3. 限额与安全

免费模式为每个 IP 和每个浏览器安装实例提供每天最多 1000 次请求。服务器会处理应用标识、浏览器随机安装标识、IP、日期及请求次数，用于限额、安全和服务统计，不用于广告画像。

4. 权限

sidePanel 用于让采集界面与来源网页并排显示；tabs 用于列出当前窗口可供用户选择的普通网页及其标题和 URL；activeTab 与 scripting 用于在用户明确选择并授权的标签页执行本地提取函数。固定主机权限只用于免费 AI 服务；可选网站权限仅在用户点击采集并确认目标网站，或配置自己的 API 地址时请求。扩展不读取浏览历史、Cookie、密码或未选择网页的正文。

5. 用户责任与保留

用户应确保有权采集和使用目标网页内容，并遵守网站条款和适用法律。字段配置保存在本地；采集结果保留在当前页面内存，用户可导出或清空。

6. 共享与出售

除提供用户主动选择的 AI 字段建议外，开发者不接收采集结果。数据不出售，不用于广告、信用评估或其他无关用途。

7. 联系方式

如有隐私或删除请求，请通过 Chrome 应用商店商品页面显示的开发者支持邮箱联系我们。
