标签页与会话管理器 · Tab Harbor 隐私政策

生效日期：2026-07-20　版本：1.0

核心承诺

本扩展不会向开发者收集、出售或共享个人信息，不投放广告，不做跨站跟踪，不加载远程代码。除下文明确说明的测速或用户主动系统分享外，功能均在用户设备本地完成。

1. 扩展用途

整理当前窗口标签页，并让用户在本机保存和恢复自定义工作区。

2. 本地处理与存储

用户保存的工作区名称、标签页标题、URL 和固定状态保存在 chrome.storage.local。

标签页信息仅用于插件核心管理功能并保存在本机。

3. 外部服务与数据传输

无。工作区数据不会同步到开发者服务器。

4. 权限用途

  • tabs：列出、切换、关闭、休眠和恢复标签页，并读取标题与 URL。
  • tabGroups：创建并命名 Chrome 原生标签组。
  • storage：保存用户主动创建的工作区。

5. 保留、删除与安全

本地数据保留至用户在插件内删除、清除 Chrome 扩展数据或卸载插件。开发者没有该数据的副本。扩展仅包含随安装包分发的 HTML、CSS、JavaScript 和图片资源。

6. 儿童、变更与联系

本扩展不面向收集儿童个人信息。政策重大变更会随扩展版本更新并修改本页日期。如有隐私问题，请通过 Chrome Web Store 产品支持页面联系开发者。
