BLE 指令面板与串口终端隐私政策

生效日期：2026 年 7 月 27 日　版本：1.0.0

本扩展不收集或上传个人数据。设备选择由 Chrome 提供的蓝牙选择器完成，指令与设备通知只在用户设备和其主动连接的 BLE 外设之间传输。

1. 产品用途

本扩展用于连接用户主动选择的 Bluetooth Low Energy（BLE）GATT/UART 外设，并通过方向键、ABXY 按键、自定义指令网格和收发终端传输用户配置的数据。它不支持经典蓝牙 SPP，也不会在后台扫描附近设备。

2. 设备访问

只有在用户点击“选择 BLE 设备”后，Chrome 才会显示系统设备选择器。扩展使用 Web Bluetooth API 访问用户在该选择器中明确授权的设备、服务与特征值。设备名称、连接状态和收到的数据仅在当前扩展页面中用于显示和操作，不会发送给开发者或第三方。

3. 本地保存的数据

用户主动保存时，配置名称、GATT 服务 UUID、特征 UUID、数据格式、分包设置、自定义按钮名称与发送代码会存入扩展自身的浏览器本地存储。终端记录仅保留在当前页面会话；重新载入页面后不会恢复。导入和导出 JSON 仅在用户明确操作时发生。

4. Chrome 权限

扩展的清单文件不申请 permissions、host_permissions 或网站访问权限。BLE 设备访问由浏览器的 Web Bluetooth 授权流程管理。扩展不读取网页内容、浏览历史、Cookie、账号、密码、位置、摄像头或麦克风。

5. 网络、共享与出售

扩展不连接开发者服务器，不包含广告、分析 SDK 或远程代码，不出售、共享或上传用户数据。BLE 指令只发送到用户主动选择且有权控制的本地外设。

6. 数据控制与删除

用户可以在扩展中逐项删除已保存配置，也可以通过 Chrome 的扩展管理页面清除扩展数据。卸载扩展会删除其浏览器本地数据；用户自行导出的 JSON 文件可在操作系统中删除。

7. 安全提示

请仅连接本人拥有或获得授权的设备，并在发送前核对指令代码。对于可能驱动电机、继电器或其他实体装置的命令，请先设置设备侧的限位、急停和安全机制。

8. 联系方式

如对本政策有疑问，请通过 Chrome 应用商店商品页面显示的开发者支持邮箱联系我们。
