网速检测 · Speed Pulse 隐私政策

生效日期：2026-07-20　版本：1.0

核心承诺

本扩展不会向开发者收集、出售或共享个人信息，不投放广告，不做跨站跟踪，不加载远程代码。除下文明确说明的测速或用户主动系统分享外，功能均在用户设备本地完成。

1. 扩展用途

通过用户主动发起的标准测试请求测量网络延迟、下载和上传吞吐量。

2. 本地处理与存储

测试时间、延迟、下载速度和上传速度保存在 chrome.storage.local。

向 Cloudflare 发送的是随机测试数据和正常网络请求元数据（例如 IP）；不会发送浏览内容。

3. 外部服务与数据传输

测速时连接 Cloudflare Speed Test（speed.cloudflare.com），下载测试字节并上传浏览器随机生成的字节；不发送网页内容或用户文件。Cloudflare 对请求的处理受其隐私政策约束。

4. 权限用途

  • storage：保存最近 5 次测速结果。
  • https://speed.cloudflare.com/*：仅在用户点击开始测速后连接 Cloudflare 官方测速端点。

5. 保留、删除与安全

本地数据保留至用户在插件内删除、清除 Chrome 扩展数据或卸载插件。开发者没有该数据的副本。扩展仅包含随安装包分发的 HTML、CSS、JavaScript 和图片资源。

6. 儿童、变更与联系

本扩展不面向收集儿童个人信息。政策重大变更会随扩展版本更新并修改本页日期。如有隐私问题，请通过 Chrome Web Store 产品支持页面联系开发者。
