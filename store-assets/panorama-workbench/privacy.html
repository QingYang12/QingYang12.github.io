360° 全景查看与导览工作台隐私政策

生效日期：2026 年 7 月 27 日　版本：1.0.0

用户选择的全景图片、热点标题和备注只在当前扩展页面本地处理，不会上传至开发者或第三方服务器。

1. 产品用途

本扩展用于打开本地 JPG、PNG 或 WebP 等距柱状全景，进行拖拽查看、缩放、自动旋转、小行星视角、画面调整、热点导览和快照导出。

2. 本地处理的数据

扩展仅在用户主动选择图片后读取图片像素、尺寸、文件名和类型。用户添加的热点方向、标题和备注只保存在当前页面内存中，除非用户主动导出为 JSON 文件。

3. 权限与网站访问

扩展不申请 Chrome permissions、host_permissions 或网站访问权限，不读取网页、浏览历史、位置、Cookie、账号或本地目录。文件选择由用户主动完成。

4. 网络、共享与出售

Three.js 与渲染代码均随扩展本地提供。扩展不发起开发者服务器请求，不加载远程代码，不使用地图、广告或分析 SDK。开发者不会接收、出售或共享图片与导览数据。

5. 输出与删除

只有用户点击快照或导览导出按钮时，浏览器才会生成 PNG 或 JSON 文件。关闭页面会清除当前图片和未导出的热点；用户可从下载目录删除导出文件。

6. 联系方式

如有疑问，请通过 Chrome 应用商店商品页面显示的开发者支持邮箱联系我们。
