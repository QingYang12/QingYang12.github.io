吉他和弦与节奏练习室隐私政策

生效日期：2026 年 7 月 27 日　版本：1.0.0

指板点击、和弦扫弦、谱例和练习记录全部在浏览器本地处理，不采集麦克风音频。

产品用途

本扩展提供六弦指板、C/G/Am/Em 开放和弦、自动扫弦、简谱/五线谱、节拍器和吉他基础。

本地数据

扩展仅保存累计发音次数和用户主动记录的音符序列。数据不会离开浏览器，卸载扩展可将其删除。

权限和网络

扩展不申请 Chrome 权限、网站访问、麦克风或摄像头权限。声音由 Web Audio API 本地生成，不连接服务器，不包含广告、分析或远程代码。

数据承诺

开发者不收集、出售或共享用户数据，不读取网站内容、历史、Cookie、账号、位置或个人通信。

联系

如有疑问，请通过 Chrome 应用商店商品页面的支持邮箱联系。
