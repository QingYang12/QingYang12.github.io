Cookie编辑器 · Cookie Studio 隐私政策

生效日期：2026-07-21　版本：1.0

核心承诺

本扩展不出售或共享用户数据，不投放广告，不做跨站跟踪，不连接开发者服务器，也不加载远程代码。

1. 单一用途

让用户查看并管理当前网站在浏览器中保存的 Cookie。

2. 数据处理

Cookie 值可能包含登录状态等敏感信息。扩展只在用户设备上处理，不上传、不分析、不出售；导出文件仅在用户主动点击后生成。

3. 权限用途

  • cookies：读取并修改用户当前访问网站的 Cookie。
  • tabs：确定当前活动标签页的网址，以限定 Cookie 管理范围。
  • http://*/* 与 https://*/*：Chrome 的 Cookie API 需要对应网站访问范围，插件只在用户当前打开的普通网页上操作。

4. 数据保留和删除

本地设置和记录保留到用户在插件内清除、清除 Chrome 扩展数据或卸载插件。开发者没有这些数据的副本。

5. 安全与第三方

所有可执行代码随安装包提供。扩展不使用分析、广告、支付或云端采集服务。

6. 联系

如有隐私问题，请通过 Chrome Web Store 产品支持页面联系开发者。
