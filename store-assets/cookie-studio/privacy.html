Cookie 透镜 · CookieLens 隐私政策

生效日期：2026-08-18　版本：1.1（随产品更名与功能更新）

核心承诺

本扩展不收集、不出售、不共享任何个人信息；不投放广告、不做跨站跟踪、不加载任何远程代码、不发起任何网络请求。它只在用户主动打开时，读取并帮助清理"用户当前正在访问的网站"的 Cookie，全部操作在本地浏览器内完成。

1. 扩展用途

对当前网站的 Cookie 做"隐私体检"：查看与搜索该网站存放的 Cookie，按作用范围（仅本站独享 / 子域共享）与存续时长（会话级 / 长期）分类，识别存续超过半年的长期 Cookie，并提供单条删除、清理长期、清空本站与 JSON 导出功能。扩展不写入、不修改、不创建任何 Cookie。

2. 数据的读取与处理

  • 扩展通过浏览器 cookies 接口读取当前网站的 Cookie 元数据（名称、域、路径、有效期等），仅用于在弹窗中展示和按用户指令删除。
  • Cookie 值在界面上默认打码显示，仅在用户主动点击时展开。
  • 导出的 JSON 文件由浏览器直接保存到用户本地磁盘，不经过任何服务器。
  • 扩展不记录浏览历史，不保存任何数据（不使用本地存储），不采集任何标识信息。

3. 外部服务与数据传输

无。扩展不与开发者服务器或任何第三方通信，不发送分析或遥测数据，全部逻辑由随包分发的本地代码执行。

4. 权限用途

  • cookies：读取与删除当前网站的 Cookie，这是本扩展唯一功能的必要条件。
  • tabs：确定用户当前正在访问的网页地址，以便针对该网站读取 Cookie；扩展不读取标签页的页面内容。
  • 主机权限（所有 http/https 网站）：Cookie 接口要求声明主机权限才能工作；扩展仅在用户主动打开弹窗时处理当前站点，不会在后台扫描或操作其他网站。

5. 保留、删除与安全

扩展本身不保留任何数据。删除操作直接作用于浏览器 Cookie 存储，立即生效且无法由扩展恢复；导出文件由用户自行保管，其中可能包含登录状态信息，请勿发送给他人。卸载扩展不会留下任何残留数据。

6. 儿童、变更与联系

本扩展不面向收集任何儿童个人信息。政策如有重大变更，将随扩展版本更新并修改本页生效日期。如有隐私问题，请通过 Chrome Web Store 产品支持页面联系开发者。
