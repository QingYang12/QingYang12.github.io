鼓组节奏编排练习室隐私政策

生效日期：2026 年 7 月 27 日　版本：1.0.0

鼓面点击、16 步节奏方格与 BPM 设置均在本地运行，不上传节奏内容。

产品用途

本扩展提供架子鼓、中国大鼓、16 步节奏编排器、节拍器、谱例与节奏基础练习。

本地数据

扩展只保存累计发音次数和用户主动记录的练习音符；当前 16 步节奏停留在页面会话中。

权限和网络

扩展不申请 Chrome 权限、网站访问、麦克风或摄像头权限。鼓声音频由 Web Audio API 本地合成，不使用服务器、广告、分析 SDK 或远程代码。

数据承诺

开发者不接收、共享或出售用户数据，也不读取网页、历史、Cookie、账号或位置。卸载扩展会移除其本地数据。
