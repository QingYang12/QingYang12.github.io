页面尺 - 像素测量工具 隐私政策

生效日期：2026-07-21　版本：1.0.1

核心承诺

本扩展不收集、存储、出售或共享任何用户数据，不投放广告，不做跨站跟踪，不连接开发者服务器。

1. 单一用途

在用户主动点击扩展图标后，在当前网页上显示本地测量层，用于测量拖拽区域的宽度、高度、坐标、面积和像素值。

2. 数据处理

鼠标位置和测量结果只在当前页面内存中临时计算，不写入浏览器存储，不上传，也不会在页面关闭后保留。

3. 权限用途

  • activeTab：仅在用户点击扩展图标后临时访问当前标签页。
  • scripting：将扩展包内的 ruler.js 注入当前标签页并显示测量界面。

4. 网络与远程代码

扩展不发起网络请求，不使用第三方服务，所有 JavaScript 和图标都包含在安装包内。

5. 删除与联系

扩展没有保存用户数据。卸载扩展即可删除全部程序文件。如有问题，请通过 Chrome Web Store 产品支持页面联系开发者。
