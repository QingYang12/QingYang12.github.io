一键缓存清理 · Clean Slate 隐私政策

生效日期：2026-07-21　版本：1.0

核心承诺

本扩展不出售或共享用户数据，不投放广告，不做跨站跟踪，不连接开发者服务器，也不加载远程代码。

1. 单一用途

让用户明确选择时间范围和数据类型后清理浏览器数据。

2. 数据处理

扩展不会读取或上传被清理的数据。默认不删除 Cookie、历史记录或本地存储；这些选项必须由用户主动勾选并确认。

3. 权限用途

  • browsingData：执行用户主动选择的浏览数据清理操作。
  • storage：在本机记住时间范围、选项和上次清理时间。

4. 数据保留和删除

本地设置和记录保留到用户在插件内清除、清除 Chrome 扩展数据或卸载插件。开发者没有这些数据的副本。

5. 安全与第三方

所有可执行代码随安装包提供。扩展不使用分析、广告、支付或云端采集服务。

6. 联系

如有隐私问题，请通过 Chrome Web Store 产品支持页面联系开发者。
