网页配色与对比度检查器隐私权政策

更新日期：2026 年 7 月 23 日

核心承诺：网页配色分析在用户浏览器本地完成。扩展不会上传网页内容、颜色结果、网址或用户色板。

1. 单一用途

本扩展扫描当前网页的 CSS 文字色、背景色、字号和字重，依据 WCAG AA/AAA 检查可读性，并提供色觉模拟、屏幕吸管、修正建议和色板导出。色觉模拟只处理用户选择的颜色数值。

2. 当前网页访问

只有用户点击“扫描当前网页”时，扩展才通过 activeTab 和 scripting 临时读取当前页面可见元素的计算样式。扩展不读取或返回元素的文字内容、表单输入、Cookie、账号信息、浏览历史或完整 HTML。

3. 本地保存

扩展使用 storage 保存用户主动添加的 HEX 色板和最近一次使用的文字色、背景色。不会保存网址、网页文字或扫描报告。用户可以随时在扩展中清空色板。

4. 数据传输

扩展不向开发者或第三方服务器传输数据，不使用统计分析、广告、跟踪或用户画像服务，不出售或共享用户数据。

5. 屏幕吸管

屏幕吸管使用浏览器提供的 EyeDropper API，在用户主动点击后返回所选像素的颜色值。扩展不会获取或保存屏幕截图。

6. 远程代码

所有 JavaScript、HTML、CSS 和图标均包含在扩展安装包中，不下载或执行远程代码。

7. Chrome 应用商店有限使用要求

本扩展对通过 Chrome API 获得的信息的使用，将遵守 Chrome 应用商店用户数据政策，包括有限使用要求。相关信息只用于用户主动请求的网页配色与对比度检查功能，不用于广告、画像、信用评估或任何无关用途，也不会交由人工查看。

8. 联系方式

如对本政策有疑问，可通过开发者在 Chrome 应用商店中公布的支持方式联系。
